Segui questi passaggi per inviare la tua prima email usando Tratto.

## Step 1: Crea la Tua API Key

Genera una API key per autenticare le richieste.

**cURL**
```bash
curl -X POST https://api.tratto.email/v1/api-keys \
  -H "Authorization: Bearer TUA_KEY_ESISTENTE" \
  -H "Content-Type: application/json" \
  -d '{"name":"quickstart"}'
```

**Node.js**
```javascript
const response = await fetch('https://api.tratto.email/v1/api-keys', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer TUA_KEY_ESISTENTE',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ name: 'quickstart' }),
});
const { data } = await response.json();
const apiKey = data.key; // tratto_live_...
```

**Python**
```python
import requests

response = requests.post(
  'https://api.tratto.email/v1/api-keys',
  headers={
    'Authorization': 'Bearer TUA_KEY_ESISTENTE',
    'Content-Type': 'application/json',
  },
  json={'name': 'quickstart'},
)
api_key = response.json()['data']['key']  # tratto_live_...
```

<Callout type="warning">
Salva la tua API key in un luogo sicuro. Viene mostrata solo una volta. Trattala come una password — non esporla mai client-side.
</Callout>

## Step 2: Aggiungi e Verifica un Dominio

Le email provengono da un dominio. Aggiungi e verifica il tuo.

**cURL**
```bash
curl -X POST https://api.tratto.email/v1/domains \
  -H "Authorization: Bearer tratto_live_..." \
  -H "Content-Type: application/json" \
  -d '{"domain":"hello.tuodominio.it"}'
```

Risposta:
```json
{
  "data": {
    "id": "dom_abc123",
    "domain": "hello.tuodominio.it",
    "status": "pending_verification",
    "records": {
      "spf": "v=spf1 include:spf.tratto.email ~all",
      "dkim": "v=DKIM1; p=MIIBIjANBg...",
      "dmarc": "v=DMARC1; p=none; rua=mailto:dmarc@tuodominio.it"
    }
  }
}
```

Aggiungi questi record DNS al tuo registrar di dominio:

| Type | Nome | Valore |
|------|------|--------|
| TXT | `hello.tuodominio.it` | `v=spf1 include:spf.tratto.email ~all` |
| TXT | `default._domainkey.hello.tuodominio.it` | (valore dalla risposta) |
| TXT | `_dmarc.hello.tuodominio.it` | `v=DMARC1; p=none; rua=mailto:dmarc@tuodominio.it` |

<Callout>
I cambiamenti DNS possono richiedere fino a 48 ore per propagarsi. Ritorna tra qualche minuto.
</Callout>

Verifica quando pronto:

**cURL**
```bash
curl -X POST https://api.tratto.email/v1/domains/dom_abc123/verify \
  -H "Authorization: Bearer tratto_live_..."
```

## Step 3: Invia la Tua Prima Email

Ora invia un'email!

**cURL**
```bash
curl -X POST https://api.tratto.email/v1/emails \
  -H "Authorization: Bearer tratto_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "from": "hello@tuodominio.it",
    "to": "tua-email@example.com",
    "subject": "Ciao da Tratto!",
    "text": "Se vedi questo, funziona!"
  }'
```

**Node.js**
```javascript
import fetch from 'node-fetch';

const response = await fetch('https://api.tratto.email/v1/emails', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer tratto_live_...',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    from: 'hello@tuodominio.it',
    to: 'tua-email@example.com',
    subject: 'Ciao da Tratto!',
    text: 'Se vedi questo, funziona!',
  }),
});
const { data } = await response.json();
console.log('Email ID:', data.id);
console.log('Status:', data.status);
```

**Python**
```python
import requests

response = requests.post(
  'https://api.tratto.email/v1/emails',
  headers={
    'Authorization': 'Bearer tratto_live_...',
    'Content-Type': 'application/json',
  },
  json={
    'from': 'hello@tuodominio.it',
    'to': 'tua-email@example.com',
    'subject': 'Ciao da Tratto!',
    'text': 'Se vedi questo, funziona!',
  },
)
data = response.json()['data']
print(f"Email ID: {data['id']}")
print(f"Status: {data['status']}")
```

Risposta:
```json
{
  "data": {
    "id": "email_xyz789",
    "status": "queued",
    "from": "hello@tuodominio.it",
    "to": "tua-email@example.com",
    "subject": "Ciao da Tratto!",
    "createdAt": "2025-06-30T12:00:00Z"
  }
}
```

## Step 4: Controlla lo Stato dell'Email

Recupera l'email per vedere se è stata consegnata.

**cURL**
```bash
curl https://api.tratto.email/v1/emails/email_xyz789 \
  -H "Authorization: Bearer tratto_live_..."
```

Cerca `status: "delivered"`.
