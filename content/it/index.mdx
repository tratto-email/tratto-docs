# Benvenuto in Tratto Docs

Tratto è una moderna piattaforma email service per sviluppatori. Questa documentazione fornisce guide, riferimenti API ed esempi per aiutarti a integrare Tratto nelle tue applicazioni.

## Cosa puoi fare con Tratto?

- **Invia email** — Email transazionali, marketing o bulk via API o SDK
- **Gestisci template** — Template email versionati con contenuto dinamico
- **Traccia eventi** — Tracking real-time di consegna, apertura, click, rimbalzo e segnalazioni
- **Automatizza flussi** — Crea flussi email automatizzati basati su trigger e condizioni
- **Analizza metriche** — Comprendi deliverability e engagement con analytics
