# Invia Email

`POST /v1/emails` è l'endpoint principale per inviare email. Invia un'email transazionale semplice, usa un template, programma per dopo, o allega file.

## Prerequisiti

Prima di poter inviare email, hai bisogno di un **dominio di invio verificato**. Vedi [Domini](/it/docs/domains) per la configurazione.

## Invio Minimo

Invia un'email di base con solo i campi obbligatori.

**cURL**
```bash
curl -X POST https://api.tratto.email/v1/emails \
  -H "Authorization: Bearer tratto_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "from": "hello@tuodominio.it",
    "to": "user@example.com",
    "subject": "Benvenuto!",
    "text": "Ciao, questa è un\'email di test."
  }'
```

**Node.js**
```javascript
const response = await fetch('https://api.tratto.email/v1/emails', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer tratto_live_...',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    from: 'hello@tuodominio.it',
    to: 'user@example.com',
    subject: 'Benvenuto!',
    text: 'Ciao, questa è un\'email di test.',
  }),
});
const { data } = await response.json();
console.log('Email inviata:', data.id);
```

**Python**
```python
import requests

response = requests.post(
  'https://api.tratto.email/v1/emails',
  headers={
    'Authorization': 'Bearer tratto_live_...',
    'Content-Type': 'application/json',
  },
  json={
    'from': 'hello@tuodominio.it',
    'to': 'user@example.com',
    'subject': 'Benvenuto!',
    'text': 'Ciao, questa è un\'email di test.',
  },
)
data = response.json()['data']
print(f"Email inviata: {data['id']}")
```

**Risposta:**
```json
{
  "data": {
    "id": "email_abc123xyz",
    "status": "queued",
    "from": "hello@tuodominio.it",
    "to": "user@example.com",
    "subject": "Benvenuto!",
    "text": "Ciao, questa è un'email di test.",
    "createdAt": "2025-06-30T12:00:00Z"
  }
}
```

## Invia con HTML

Includi sia `text` (fallback) che `html` (contenuto renderizzato):

```bash
curl -X POST https://api.tratto.email/v1/emails \
  -H "Authorization: Bearer tratto_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "from": "hello@tuodominio.it",
    "to": "user@example.com",
    "subject": "Benvenuto!",
    "text": "Ciao, questa è un\'email di test.",
    "html": "<h1>Ciao!</h1><p>Questa è un\'email di test.</p>"
  }'
```

I client email mostrano `html` se supportato; ricadere a `text` altrimenti.

## Invia con un Template

Invece di comporre HTML nel codice, usa un template con sostituzione di variabili.

**Step 1: Crea un template (vedi [Template](/it/docs/templates))**

```json
{
  "name": "Email di Benvenuto",
  "subject": "Benvenuto, {{firstName}}!",
  "text": "Ciao {{firstName}}!",
  "html": "<h1>Ciao {{firstName}}!</h1><p>Il tuo codice: {{code}}</p>"
}
```

**Step 2: Invia usando il template**

```bash
curl -X POST https://api.tratto.email/v1/emails \
  -H "Authorization: Bearer tratto_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "from": "hello@tuodominio.it",
    "to": "user@example.com",
    "templateId": "tmpl_abc123",
    "variables": {
      "firstName": "Alice",
      "code": "SECRET123"
    }
  }'
```

L'`subject`, `text`, e `html` del template vengono renderizzati con le variabili fornite.

## Programma un'Email

Invia un'email a un orario futuro usando il campo `scheduledAt` (formato ISO 8601):

```bash
curl -X POST https://api.tratto.email/v1/emails \
  -H "Authorization: Bearer tratto_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "from": "hello@tuodominio.it",
    "to": "user@example.com",
    "subject": "Promemoria!",
    "text": "Ci vediamo domani.",
    "scheduledAt": "2025-07-01T09:00:00Z"
  }'
```

L'email verrà messa in coda e inviata all'orario specificato (deve essere nel futuro).

## Aggiungi Allegati

Includi file come allegati codificati in base64:

```bash
curl -X POST https://api.tratto.email/v1/emails \
  -H "Authorization: Bearer tratto_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "from": "hello@tuodominio.it",
    "to": "user@example.com",
    "subject": "Fattura",
    "text": "Vedi allegato fattura.",
    "attachments": [
      {
        "filename": "fattura.pdf",
        "contentType": "application/pdf",
        "content": "JVBERi0xLjQKJeLj..."
      }
    ]
  }'
```

**Passaggi per allegare un file:**

1. Leggi il file come binario
2. Codifica il contenuto in base64
3. Includi `filename`, `contentType`, e `content` nell'array `attachments`

**Esempio JavaScript:**
```javascript
const fs = require('fs');

const fileBuffer = fs.readFileSync('fattura.pdf');
const base64Content = fileBuffer.toString('base64');

const attachments = [
  {
    filename: 'fattura.pdf',
    contentType: 'application/pdf',
    content: base64Content,
  },
];
```

## Tag per l'Organizzazione

Aggiungi tag per organizzare e filtrare le email:

```bash
curl -X POST https://api.tratto.email/v1/emails \
  -H "Authorization: Bearer tratto_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "from": "hello@tuodominio.it",
    "to": "user@example.com",
    "subject": "Conferma Ordine",
    "text": "Il tuo ordine è stato confermato.",
    "tags": ["ordine", "transazionale"]
  }'
```

Successivamente, filtra le email per tag o usali nei webhook.

## Riferimento Completo del Request Body

| Campo | Tipo | Obbligatorio | Descrizione |
|-------|------|--------------|-------------|
| `from` | string | ✓ | Indirizzo email del mittente (deve essere da un dominio verificato) |
| `to` | string | ✓ | Indirizzo email del destinatario |
| `cc` | string[] | | Destinatari di copia carbone |
| `bcc` | string[] | | Destinatari di copia carbone nascosta |
| `subject` | string | ✓ (se non usi template) | Riga di oggetto dell'email |
| `text` | string | | Contenuto testo semplice (usato come fallback) |
| `html` | string | | Contenuto HTML |
| `templateId` | string | | Template ID (al posto di `subject`/`text`/`html`) |
| `variables` | object | | Variabili da interpolate nel template |
| `attachments` | array | | Array di oggetti allegati |
| `scheduledAt` | string (ISO 8601) | | Programma email per consegna futura |
| `tags` | string[] | | Tag di organizzazione (max 10) |
| `replyTo` | string | | Indirizzo di risposta |
| `headers` | object | | Custom email headers (avanzato) |

## Risposta

**Successo (2xx):**
```json
{
  "data": {
    "id": "email_abc123xyz",
    "status": "queued",
    "from": "hello@tuodominio.it",
    "to": "user@example.com",
    "cc": [],
    "bcc": [],
    "subject": "Benvenuto!",
    "createdAt": "2025-06-30T12:00:00Z",
    "scheduledAt": null
  }
}
```

**Errore (4xx):**
```json
{
  "error": {
    "code": "FORBIDDEN",
    "message": "The sending domain is not verified.",
    "docs": "https://docs.tratto.email/it/domains",
    "suggestion": "Add and verify the domain at https://app.tratto.email/domains before sending."
  }
}
```

## Errori Comuni

### FORBIDDEN — dominio non verificato

**Causa:** Il dominio `from` non è ancora verificato. L'API restituisce 403 con il
dominio indicato in `message`.

**Fix:** Completa il [processo di verifica del dominio](/it/docs/domains).

### RATE_LIMITED

**Causa:** Hai superato il limite di 500 richieste al minuto.

**Fix:** Implementa backoff esponenziale e riprova più tardi. Vedi [Rate Limits](/it/docs/rate-limits).

### VALIDATION_ERROR

**Causa:** Richiesta non valida (campo mancante, JSON malformato, ecc.).

**Fix:** Controlla il messaggio di errore e consulta il riferimento [Codici di Errore](/it/docs/error-codes).
