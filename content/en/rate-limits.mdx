# Rate Limits & Quotas

## Global Rate Limit

**500 requests per minute** per tenant. This applies to all API endpoints combined.

## Rate Limit Headers

Every response includes rate limit info:

```http
x-ratelimit-limit: 500
x-ratelimit-remaining: 245
x-ratelimit-reset: 47
```

`x-ratelimit-reset` is the number of **seconds remaining** in the current window,
not a Unix timestamp. On a 429 the response also carries a `retry-after` header,
in seconds.

## Check Rate Limit Status

Before hitting the limit, check the headers:

```bash
curl -i https://api.tratto.email/v1/emails \
  -H "Authorization: Bearer tratto_live_..."
```

Returns headers with remaining requests and reset time.

## Rate Limit Exceeded (429)

When you exceed the limit:

```json
{
  "error": {
    "code": "RATE_LIMITED",
    "message": "Too many requests. Slow down.",
    "docs": "https://tratto.email/docs/api/errors#rate_limited"
  }
}
```

The response carries no `retryAfter` field — use the `x-ratelimit-reset` header
and your own backoff.

## Retry Strategy

Use **exponential backoff with jitter**:

```javascript
async function sendWithRetry(request, maxRetries = 3) {
  for (let attempt = 0; attempt < maxRetries; attempt++) {
    try {
      return await fetch(request);
    } catch (error) {
      if (error.status === 429) {
        const delay = Math.pow(2, attempt) * 1000 + Math.random() * 1000;
        await new Promise(r => setTimeout(r, delay));
      } else {
        throw error;
      }
    }
  }
}
```

## Email Volume Quotas

Limits per plan (rolling 30-day window):

| Plan | Monthly Emails | Daily Limit |
|------|---|---|
| Free | 1,000 | 33 |
| Starter | 10,000 | 333 |
| Growth | 100,000 | 3,333 |
| Pro | Unlimited | Unlimited |

Exceed your quota and requests fail with `QUOTA_EXCEEDED`, which also returns
429. Unlike `RATE_LIMITED` it will not clear by retrying — see
[Error Codes](/en/docs/error-codes).

## Burst Behavior

Short bursts (seconds) can exceed `x-ratelimit-remaining` due to asynchronous processing. The 500 req/min limit is a hard cap; short peaks are allowed if average stays under the limit.
