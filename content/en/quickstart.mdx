# Quickstart: Send Your First Email in 5 Minutes

Follow these steps to send your first email using Tratto.

## Step 1: Create Your API Key

Generate an API key to authenticate requests.

**cURL**
```bash
curl -X POST https://api.tratto.email/v1/api-keys \
  -H "Authorization: Bearer YOUR_EXISTING_KEY" \
  -H "Content-Type: application/json" \
  -d '{"name":"quickstart"}'
```

**Node.js**
```javascript
const response = await fetch('https://api.tratto.email/v1/api-keys', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer YOUR_EXISTING_KEY',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({ name: 'quickstart' }),
});
const { data } = await response.json();
const apiKey = data.key; // tratto_live_...
```

**Python**
```python
import requests

response = requests.post(
  'https://api.tratto.email/v1/api-keys',
  headers={
    'Authorization': 'Bearer YOUR_EXISTING_KEY',
    'Content-Type': 'application/json',
  },
  json={'name': 'quickstart'},
)
api_key = response.json()['data']['key']  # tratto_live_...
```

<Callout type="warning">
Save your API key somewhere safe. It's shown only once. Treat it like a password — never expose it client-side.
</Callout>

## Step 2: Add and Verify a Domain

Email comes from a domain. Add and verify yours.

**cURL**
```bash
curl -X POST https://api.tratto.email/v1/domains \
  -H "Authorization: Bearer tratto_live_..." \
  -H "Content-Type: application/json" \
  -d '{"domain":"hello.yourdomain.com"}'
```

Response:
```json
{
  "data": {
    "id": "dom_abc123",
    "domain": "hello.yourdomain.com",
    "status": "pending_verification",
    "records": {
      "spf": "v=spf1 include:spf.tratto.email ~all",
      "dkim": "v=DKIM1; p=MIIBIjANBg...",
      "dmarc": "v=DMARC1; p=none; rua=mailto:dmarc@yourdomain.com"
    }
  }
}
```

Add these DNS records to your domain registrar:

| Type | Name | Value |
|------|------|-------|
| TXT | `hello.yourdomain.com` | `v=spf1 include:spf.tratto.email ~all` |
| TXT | `default._domainkey.hello.yourdomain.com` | (value from response) |
| TXT | `_dmarc.hello.yourdomain.com` | `v=DMARC1; p=none; rua=mailto:dmarc@yourdomain.com` |

<Callout>
DNS changes can take up to 48 hours to propagate. Check back in a few minutes.
</Callout>

Verify when ready:

**cURL**
```bash
curl -X POST https://api.tratto.email/v1/domains/dom_abc123/verify \
  -H "Authorization: Bearer tratto_live_..."
```

## Step 3: Send Your First Email

Now send an email!

**cURL**
```bash
curl -X POST https://api.tratto.email/v1/emails \
  -H "Authorization: Bearer tratto_live_..." \
  -H "Content-Type: application/json" \
  -d '{
    "from": "hello@yourdomain.com",
    "to": "your-email@example.com",
    "subject": "Hello from Tratto!",
    "text": "If you see this, it works!"
  }'
```

**Node.js**
```javascript
import fetch from 'node-fetch';

const response = await fetch('https://api.tratto.email/v1/emails', {
  method: 'POST',
  headers: {
    'Authorization': 'Bearer tratto_live_...',
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    from: 'hello@yourdomain.com',
    to: 'your-email@example.com',
    subject: 'Hello from Tratto!',
    text: 'If you see this, it works!',
  }),
});
const { data } = await response.json();
console.log('Email ID:', data.id);
console.log('Status:', data.status);
```

**Python**
```python
import requests

response = requests.post(
  'https://api.tratto.email/v1/emails',
  headers={
    'Authorization': 'Bearer tratto_live_...',
    'Content-Type': 'application/json',
  },
  json={
    'from': 'hello@yourdomain.com',
    'to': 'your-email@example.com',
    'subject': 'Hello from Tratto!',
    'text': 'If you see this, it works!',
  },
)
data = response.json()['data']
print(f"Email ID: {data['id']}")
print(f"Status: {data['status']}")
```

Response:
```json
{
  "data": {
    "id": "email_xyz789",
    "status": "queued",
    "from": "hello@yourdomain.com",
    "to": "your-email@example.com",
    "subject": "Hello from Tratto!",
    "createdAt": "2025-06-30T12:00:00Z"
  }
}
```

## Step 4: Check Email Status

Retrieve the email to see if it was delivered.

**cURL**
```bash
curl https://api.tratto.email/v1/emails/email_xyz789 \
  -H "Authorization: Bearer tratto_live_..."
```

Look for `status: "delivered"`.
